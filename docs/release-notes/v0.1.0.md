**Test build — the first playable slice of couch co-op.** A second controller joins
an offline game and plays its own hero on the shared screen while pad 1 keeps every
normal control. Pad 1's inventory, character sheet or spellbook never stops the other
player.

How to play: start **Multi Player → Offline**, create a game, press any button on
pad 1, then press **Start on a second controller**. Guest controls: stick/D-pad walk,
A attack or pick up, X cast, Y next spell, B drink a potion. Full details and limits:
[docs/LOCAL-COOP.md](https://github.com/jarvis-jhk/diablo-splitscreen/blob/master/docs/LOCAL-COOP.md).

Known limits of this build: guests are **not saved** (they play a read-only copy of
another saved hero, or a new one), have no inventory or shop yet, follow pad 1 between
levels, and the camera follows pad 1. Tested with virtual controllers only — please try
it with real pads (and on the Deck) and report what feels wrong.

You need your own `DIABDAT.MPQ` (or `spawn.mpq` for shareware); no game data is included.
Linux and Steam Deck: unpack the `.tar.gz` and run `diablo-splitscreen/diablo-splitscreen.sh`
(it starts the bundled AppImage). Windows: unpack the zip and run `diablo-splitscreen\devilutionx.exe`.
This build sends an anonymous report (version, platform, "fatal error"/crash signal —
nothing else) if the game fails; set `DEVILUTIONX_NO_REPORT=1` to turn that off.
No automatic updates yet. Not an official DevilutionX release; based on DevilutionX
under its Sustainable Use License.
