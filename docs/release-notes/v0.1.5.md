**Test build — saved guest heroes.** Second, third and fourth players now keep their
progress: a guest's level, experience, stats, gold and items are saved to its own hero
whenever pad 1's hero is saved (changing level, every minute, quitting) and when the
guest leaves. A new guest hero ("Player 2" and so on) gets a save slot of its own right
away, so next time it is in the join panel like any other saved hero. A guest never
writes pad 1's save or a slot that already holds a file.

Still from v0.1.4: unplugging a guest's controller leaves the hero standing; **Start on
any free controller** plays on with it.

Still from v0.1.3: the camera centres on the middle of all heroes, and every player
(pad 1 too) can walk as far as the screen allows.

Still from v0.1.2: press **Start on a free controller** to open the join panel (saved
hero or new hero, A joins, B cancels); Start on a guest's controller asks to leave.

Still from v0.1.1: **Back on a guest's controller** opens that player's own inventory
(A wear/use, Y belt, X drop, B close) while everyone else keeps playing. Start
**Multi Player → Offline**, create a game, press any button on pad 1, then Start on
another controller. Guest controls: stick/D-pad walk, A attack or pick up, X cast,
Y next spell, B drink a potion. Full details and limits:
[docs/LOCAL-COOP.md](https://github.com/jarvis-jhk/diablo-splitscreen/blob/master/docs/LOCAL-COOP.md).

Known limits of this build: as in any multiplayer game only heroes are saved, not
the dungeon or quest progress; guests have no character sheet, spellbook or shop yet, cannot split gold or use cursor
scrolls/oils, follow pad 1 between levels. Tested with
virtual controllers only — please try it with real pads (and on the Deck) and report
what feels wrong.

You need your own `DIABDAT.MPQ` (or `spawn.mpq` for shareware); no game data is included.
Linux and Steam Deck: unpack the `.tar.gz` and run `diablo-splitscreen/diablo-splitscreen.sh`
(it starts the bundled AppImage; needs glibc 2.38 or newer, e.g. current SteamOS or Ubuntu 24.04). Windows: unpack the zip and run `diablo-splitscreen\devilutionx.exe`.
This build sends an anonymous report (version, platform, "fatal error"/crash signal —
nothing else) if the game fails; set `DEVILUTIONX_NO_REPORT=1` to turn that off.
No automatic updates yet. Not an official DevilutionX release; based on DevilutionX
under its Sustainable Use License.
