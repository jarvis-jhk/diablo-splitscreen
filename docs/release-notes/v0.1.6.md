**Test build — Linux and Steam Deck installer.** Download
`Install-Diablo-Splitscreen.desktop` and double-click it (on the Deck in desktop mode),
or run `bash install.sh`. It downloads this release's Linux build, checks it against
`SHA256SUMS`, installs it to `~/.local/share/diablo-splitscreen` (the previous version is
kept for going back), adds a menu entry, offers to copy your own `DIABDAT.MPQ` to where
the game looks for it, and adds a Steam shortcut for Game Mode when Steam is closed (a
backup of Steam's shortcut file is kept). Saves, settings and game data are never
touched. Running a newer release's installer updates; the shortcut keeps working.

The game itself is unchanged from v0.1.5: up to four controllers on one shared screen,
Start on a free controller joins with a saved or new hero, Back opens a guest's own
inventory while everyone keeps playing, guest heroes are saved, unplugged guests wait
for any free controller. Full details and limits:
[docs/LOCAL-COOP.md](https://github.com/jarvis-jhk/diablo-splitscreen/blob/master/docs/LOCAL-COOP.md).

Known limits: as in any multiplayer game only heroes are saved, not the dungeon or quest
progress; guests have no character sheet, spellbook or shop yet and follow pad 1 between
levels. No automatic update check yet: run the new installer. Tested with virtual
controllers and in a scripted installer test only — please try it on the Deck and with
real pads and report what feels wrong.

You need your own `DIABDAT.MPQ` (or `spawn.mpq` for shareware); no game data is included.
The Linux build needs glibc 2.38 or newer (current SteamOS, Ubuntu 24.04). Without the
installer: unpack the `.tar.gz` and run `diablo-splitscreen/diablo-splitscreen.sh`.
Windows: unpack the zip and run `diablo-splitscreen\devilutionx.exe`.
This build sends an anonymous report (version, platform, "fatal error"/crash signal or
the failed installer step — nothing else) if something fails; set
`DEVILUTIONX_NO_REPORT=1` to turn that off. Not an official DevilutionX release; based
on DevilutionX under its Sustainable Use License.
