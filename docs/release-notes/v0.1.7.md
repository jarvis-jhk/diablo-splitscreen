**Test build — automatic updates on Linux and Steam Deck.** From this version on, a game
installed with the installer updates itself: while you play it checks GitHub (at most
every six hours) for a newer Diablo Splitscreen release, downloads it in the background
and checks it against that release's `SHA256SUMS`. Nothing changes during that game; the
next start switches to the new version, but only after its binary has started once on
your system. If a new version crashes within its first minute, the game goes back to the
version you had and starts that instead, and never offers the broken one again. Offline,
it simply starts. Saves, settings and game data are never touched; the menu entry and
Steam shortcut keep working. Turn it off by creating
`~/.local/share/diablo-splitscreen/no-auto-update`.

**To get it, install this version once with its installer** (v0.1.6 and older cannot
update themselves): download `Install-Diablo-Splitscreen.desktop` and double-click it (on
the Deck in desktop mode), or run `bash install.sh`. An unpacked `.tar.gz` or a Warpzone
install never updates itself. Windows has no automatic update yet.

The game itself is unchanged from v0.1.6: up to four controllers on one shared screen,
Start on a free controller joins with a saved or new hero, Back opens a guest's own
inventory while everyone keeps playing, guest heroes are saved, unplugged guests wait
for any free controller. Full details and limits:
[docs/LOCAL-COOP.md](https://github.com/jarvis-jhk/diablo-splitscreen/blob/master/docs/LOCAL-COOP.md).

Known limits: as in any multiplayer game only heroes are saved, not the dungeon or quest
progress; guests have no character sheet, spellbook or shop yet and follow pad 1 between
levels; no changelog is shown after an update yet. Updates were tested in a scripted test
with fake releases and against this release's real build only — please report anything
odd from the Deck.

You need your own `DIABDAT.MPQ` (or `spawn.mpq` for shareware); no game data is included.
The Linux build needs glibc 2.38 or newer (current SteamOS, Ubuntu 24.04). Without the
installer: unpack the `.tar.gz` and run `diablo-splitscreen/diablo-splitscreen.sh`.
Windows: unpack the zip and run `diablo-splitscreen\devilutionx.exe`.
This build sends an anonymous report (version, platform, "fatal error"/crash signal, the
failed installer step or a failed update check/rollback — nothing else) if something
fails; set `DEVILUTIONX_NO_REPORT=1` to turn that off. Not an official DevilutionX
release; based on DevilutionX under its Sustainable Use License.
